# 真模型端到端验证（非 mock）

知识库：本仓库 `tools/make_demo_kb.py` 生成的**虚拟**演示库（张三/李四/大学同学群，无任何真实聊天）

模型：任意 OpenAI 兼容接口（本机自建网关 / 火山方舟 / OpenAI / DeepSeek / Ollama 均可）

命令：

```bash
python -m wxreply once --kb <演示库> --chat 张三 --label '联系人 1' --note '同事，不用太客气' \
  --text '对了，评审材料我还没写完，第3页的指标数据要不你先帮我讲一下？我晚上补上' \
  --refine '别催他，轻松一点，顺便问下他周末有没有空'
```

输出：

```text
对象：联系人 1 · 张三
对方：[10-07 22:57] 张三: 对了，评审材料我还没写完，第3页的指标数据要不你先帮我讲一下？我晚上补上
意图：想让帮忙讲第3页指标数据，等你表态是否能接。

[1] 稳妥（风险 低）
    我先看下第3页数据，再看能不能讲。
    理由：不直接答应，先确认自己能不能讲，给对方回应但不背锅。

[2] 轻松（风险 低）
    哈哈行啊，你先把第3页数据丢我，我看看。
    理由：语气松弛，也提醒他先给材料，不会显得生硬。

[3] 直球（风险 中）
    你先发我，能讲我就讲，不行你别等我。
    理由：把边界说清楚，避免对方默认你一定会兜底。

[4] 简短（风险 低）
    第3页数据发我看看。
    理由：随手要材料，不急着表态，符合微信短回复。

按意见「别催他，轻松一点，顺便问下他周末有没有空」改写后：
    行，我先看看第3页数据，再看能不能讲。对了，你周末有空吗？
```

退出码：0
